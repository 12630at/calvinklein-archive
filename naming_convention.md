# Calvin Klein Print Archive — Naming Convention

## Struttura del nome file

### ADV (advertising)

```
YYYY_[ss/fw]_adv_print_CATEGORIA_NNN.webp
```

| Token | Descrizione | Esempi |
|---|---|---|
| `YYYY` | Anno della campagna | `1993`, `2006` |
| `ss` / `fw` | Stagione — primavera/estate o autunno/inverno | `ss`, `fw` |
| `adv_print` | Tipo di materiale (fisso) | `adv_print` |
| `CATEGORIA` | Categoria e sottocategoria (vedi sotto) | `collection`, `fragrance_one` |
| `NNN` | Numero progressivo a 3 cifre | `001`, `002` |

### EDI (editorial)

```
YYYY_edi_TESTATA_NNN.webp
```

| Token | Descrizione | Esempi |
|---|---|---|
| `YYYY` | Anno di pubblicazione | `1995`, `2000` |
| `edi` | Tipo di materiale (fisso) | `edi` |
| `TESTATA` | Codice testata (vedi sotto) | `theface`, `vogueus` |
| `NNN` | Numero progressivo a 3 cifre | `001`, `002` |

> Le editoriali **non** portano la stagione nel nome file.

## Categorie ADV

### Collection

| Categoria | Descrizione |
|---|---|
| `collection` | Campagna womenswear principale |
| `collection_ck` | Linea CK (diffusione) |
| `collection_menswear` | Campagna menswear |

### Fragrance

La fragrance segue sempre la struttura `fragrance_[nome]` e, quando si tratta di comunicazione maschile dedicata, `fragrance_[nome]_men`.
